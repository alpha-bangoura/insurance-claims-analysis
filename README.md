# Insurance Claims Analysis

## Project Overview
This project simulates an insurance portfolio and analyzes claim activity using Python and Excel.

## Tools Used
- Python
- Pandas
- Microsoft Excel
- PivotTables
- PivotCharts

## Key Metrics Calculated
- Total Policies: 500
- Total Claims: 75
- Claim Frequency: 15%
- Claim Severity: $9,974.93
- Expected Loss: $1,496.24

## Analysis Performed
- Generated synthetic insurance policy data using Python.
- Created an insurance claims dataset containing 500 policies.
- Calculated claim frequency and claim severity.
- Computed expected loss using actuarial frequency-severity methods.
- Analyzed claims by state.
- Analyzed claims by age group.
- Created PivotTables and PivotCharts to visualize results.
